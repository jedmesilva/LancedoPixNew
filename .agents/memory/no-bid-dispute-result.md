---
name: No-bid dispute result
description: Product rule for presenting disputes that expire without any bids.
---

When a dispute ends without bids, use the same result-row hierarchy as a win: label it “Lance vencedor”, show “Nenhum” in the value slot, and use “Ninguém venceu a disputa” as supporting copy. Keep the trophy muted gray on a neutral background and omit the winning check and green victory treatment. Never show R$0 as a winning bid.

**Why:** The user wants the no-bid outcome to keep the familiar result layout while making it visually distinct from an actual win.

**How to apply:** Preserve the winner row's typography and alignment, but use the no-bid copy and neutral gray styling for no-bid results. Keep the regular winning amount, trophy color, check, and green styling only for actual wins.
