---
name: Direct UI implementation
description: User preference for implementing requested UI changes in the app without opening a canvas.
---

When the user asks for a direct UI change, implement it in the application and verify the app preview. Do not create canvas mockups unless the user explicitly asks for canvas or design iteration.

**Why:** The user corrected a canvas mockup being created instead of implementing the requested feature.

**How to apply:** Treat a concrete request to add or change app UI as permission to edit the existing app directly; reserve canvas work for explicit canvas requests.
